Develop

Requires JDK 25.

./gradlew clean buildAll

This runs the tests and builds the jar into build/libs/.

Rebuild the icon and pause menu button from the game's textures:

java scripts/MakeIcon.java <26.3 client jar> src/main/resources/assets/cuemymusic/icon.png src/main/resources/assets/cuemymusic/textures/gui/sprites/music.png

Add-ons

Give an add-on a page in the player: implement mix.cuemymusic.api.CuePanel and call CuePanels.register(panel) from your client initializer. Draw it with PanelCanvas. The API may still change.
