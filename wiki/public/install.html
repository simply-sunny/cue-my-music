Documentation / Install

Install

Recommended: Prism Launcher

  1. Create or select an instance with the Minecraft version and loader listed below.
  2. Open Edit → Mods → Download Mods. Find the mod on Modrinth or CurseForge where it is listed, and install its required dependencies.
  3. If the mod is not listed there, download its JAR from the project’s release page and add it to the instance’s mods folder.
  4. Complete the project-specific setup below, then launch the instance.
