Install

For Minecraft 26.3 on Fabric or Quilt. Java 25. Client-side only.

  1. Install Fabric Loader or Quilt Loader.
  2. Install Fabric API.
  3. Install Mod Menu 21.0.0 or newer.
  4. Put the jar in mods.
